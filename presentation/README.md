# Sales material — NFC review signs, South Lake Tahoe

Print-ready material to hand to a manager or owner during a walk-in visit.
Both files are plain HTML rendered to PDF with WeasyPrint; edit the HTML and
re-run `./build.sh`.

| File | Pages | Use |
| --- | --- | --- |
| `one-pager.html` / `.pdf` | 1 | The leave-behind. Hand it over with the sample; it explains the product, how it works, the price and how to reach me. |
| `presentation-3pages.html` / `.pdf` | 3 | The longer version, for someone who has to run it past an owner or a district manager. |

Both are US Letter, print in colour, and are written for the person on the
other side of the counter — English, no jargon, no claims that aren't backed
by the research in the plan.

Contact block on both: (385) 395-2285 · nicolas10ledesma@gmail.com

## Editing

* Prices live in the `.card` blocks (`$79` / `$149`).
* The contact band is the last `<section class="contact">` of each file.
* Anything printed in the pieces themselves (the 2×8 inserts) is a separate
  artefact, not in this folder.
